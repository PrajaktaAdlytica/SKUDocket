Chosen identity: Docket Fold (logo option 1).

Positioning and voice
Prepare repeat-SKU import dossiers for broker review. Primary buyer: US importer-of-record compliance lead with recurring SKUs, multiple suppliers and a broker. Use concrete language about evidence, assumptions, sources, missing proof and reviewer actions. Preserve all five separately testable offers. Product capability, demand, price acceptance and live integrations are research-stage hypotheses.

Logo
Use the primary horizontal signature for first contact. Compact Docket Fold mark for favicon and constrained spaces. Clear space: 1/4 mark height. Horizontal logo minimum 28px high; small-size compact mark minimum 16px, with optical simplified geometry in the smallest favicon. Color, ink, reverse, black, white, stacked and wordmark-only SVGs supplied. Wordmark outlines use Source Serif 4 at weight 650 and optical size 60; preserve outline proportions and kerning. The SVG is a geometry recreation of the selected generated concept, with licensed type substituted for the generated lettering. No live font required to render logo. Never distort, add certification seals or substitute status green for coral.

Color
Oyster #FAF7EF canvas; white #FFFFFF evidence surface; paper #F2EEE5 muted surface; maritime #263C4C text and mark; muted #5B6870 secondary text; coral #AF5A56 brand; action #98443F and hover #803531; blue #667F99; pale sage #D6E1D5; butter #F0E4BA.
Semantic text: hold #835510 on #FFF1CF; error #9D353A on #FCE7E7; info #3B617D on #E7EFF5; completed task #31604F on #E4EFE7. A green task status never means cleared or compliant. Pale accents are backgrounds, not small-text colors. Defined pairs have measured contrast evidence in contrast-checks.json. Neutral structural dividers can be faint; interactive control edges use #81888A. Use text/icons alongside status color.
The ink section changes surfaces and text; it is a composed marketing chapter, not a claim that a complete dark-mode application has been implemented.

Typography
Two font families only. Source Serif 4: display/headings, editorial quotes and document titles. Public Sans: body/UI, labels, buttons, charts, tables. Roman/italic TTF and WOFF2 files included with OFL notices. Source Serif variable weight 200–900, optical-size 8–60 verified from downloaded binary. Public Sans variable weight 100–900; upstream identifies variable font builds as experimental. These exact bundled files loaded successfully during browser checks.
Display 72px desktop, 42px mobile; H1 64/38; H2 48/30; H3 32/24; H4 24; H5 20; H6 18. See responsive clamp values in design-tokens.json. Headings use 600, UI labels 600, body 400. Headline tracking -0.025 to -0.035em; short eyebrow tracking .14em. Body 16px with 1.6 line height; UI 14px/1.45; caption 12px/1.5; lead 20px/1.5. Use font-variant-numeric: tabular-nums for amounts, dates and quantity columns. Never stretch letters, use uppercase paragraphs or set essential document details below readable size.

Default panels use borders; card shadow is low elevation; raised shadow only for selected evidence/hero contexts; overlay shadow only for dialogs/menus. No nested card stacks, giant glow effects, blurred glass or unrelated floating 3D objects.

Buttons and CTA hierarchy
Default48px high, large56, compact40. Primary body14–15px/600, padding20px (24large). Primary explores the demo or discusses a pilot; one primary per decision area. Secondary ink outline, tertiary text+arrow, icon-only48px with accessible name. Hover darkeraction and arrowadvance4px; pressed1px; focus2px ring with4px offset; loading preserves width and exposes aria-busy; disabled states retain readable labels and actual disabled behavior. No active checkout for hypothetical pricing. All route CTAs defined in the visual plan. Labels describe concrete tasks: View source, Review blockers, Compare rationales, Preview packet, Return for revision.

Flip and shutter motion
Button shutter: two surface halves enter over280ms behind a stable label. Button flip: duplicate visual label moves over280ms, with one stable accessible name. Card flip: only optional source context; mandatory status and reveal action stay outside the faces. Pointer hover temporarily previews, an explicit button pins/unpins for touch/keyboard, Escape returns; inactive face aria-hidden/inert. 360ms ease. Reduced motion swaps content immediately rather than rotating. Shutter card: four decorative slats retreat; essential copy/CTA never hidden. No random tilt, disorienting parallax or hover-only decision.
Micro120ms; control180; shutter280; flip360; chapter480. Ease cubic-bezier(.2,.8,.2,1). Native scrolling. Background art stays still by default. Any later autoplay explainers must include pause and skip and must never approve a record or resolve a screening match.

Cards and section visual language
Offer1 comparison spread, two hypotheses and source facts; offer2 supplier/evidence checklist; offer3 identifier comparison and unresolved match; offer4 bars/scenario assumptions; offer5 manifest with provenance connectors. Five independent simplified card SVGs supplied, distinct from large figures. Other card families: evidence folio, source version/date card, exception notice, reviewer note, resource shutter, optional source flip, pilot scorecard, pricing scope panel. Each card represents one object and one next action. Each section uses an intentional environment: cream editorial chapter, white workbench, ruled index, pale evidence spread, ink responsibility chapter or coral folded-document transition. Avoid repeating one component grid through the whole site.

Images and illustration
Original Harbor Atlas for homepage geography and commerce; Review Table for human review/method/about. Atmospheric imagery never substitutes for product evidence. PNG masters/WebP optimized files included. Prefer wide natural crops; no stretching; keep detail away from primary copy and preserve negative space. Figures on clean UI surfaces retain crisp lines and readable labels; textures sit behind illustration, not tables. Do not use downloaded inspirational collages as site assets. Alt text describes the useful content. Mobile simplifies crop while preserving the task.

Diagrams and chart rules
Use source → assumption → exception → reviewer → packet relationships. Connect node edges, keep arrows outside labels and preserve versions/dates. Classification is a two-branch comparison, not an AI-confidence gauge. Screening is identifier review, not an automatic-clearance badge. Origin is evidence completeness, not eligibility implied by a check. Packet is provenance plus open issues, not an entry filing.
Use bars for A/B costs; waterfall for included components; line for a dated simulated change; pie/donut only for mutually exclusive states of a defined whole. Charts have labels, units, legend, synthetic disclosure and equivalent data table. Never random performance curves, fabricated savings, customer metrics, 3D pies, gauge-style compliance scores or a live badge without a real feed.
All queue pie/donut counts derive from the ten-record fixture:2held,2pending,1collected,2broker review,2exported,1rejected. CostA=$13,310;B=$13,550 for1000units, invented4%/6% rates. Difference240 is a scenario difference, not savings. Includes goods12000, freight600, insurance80, broker150; excludes unassessed adjustments/other charges. Source/list fixture dates are demo dates, not government feed claims.

Forms, navigation, footer and ancillary states
Use visible labels, helpful inline errors, required indicators, appropriate autocomplete, separate unchecked inquiry/updates consent, a purpose notice and a deletion route. Do not show success before storage succeeds. No sensitive record uploads belong in the waitlist/demo. No password field should pretend to connect to active customer accounts.
Navigation needs clear groups for all five offers, audience/workflow/resources and demo/pilot. Mobile expands groups in reading order and preserves focus and close behavior. The footer has Product, Workflows, Evaluate and Company groups plus independent LinkedIn and Crunchbase profile icons. No profile URLs have been supplied: preview marks are inactive buttons rather than meaningless links.
The original social assets remain their owners' trademarks. The Crunchbase SVG embeds the unmodified official raster icon; an original PNG and official vector wordmark are supplied. UI icons are 59 Lucide SVGs with ISC/MIT notices. Default size 20px and stroke 1.75px; support 16/20/24/32px. Icon-only buttons need accessible names. Primary touch interactions should target at least 44px.

Ancillary components
Empty states explain absent evidence and the specific next action. Errors preserve input. Stale-source states show last known dates and a re-review task. Toast/status regions describe success only after confirmation. Tabs preserve selection and focus; modals close with Escape and return focus. Breadcrumbs tie an entry reference to a SKU and packet. Table headers show units; numeric columns align right. Customer, integration, certification and news claims require real approved evidence. No empty routes or invented customer proof.

Handoff and limits
Assets, token CSS/JSON, optional Tailwind mapping, fonts/licenses, the interactive catalog and page recipes are included. This is a brand kit; the planned 31-page company website remains a separate implementation. Backend forms/auth, operator facts and final legal copy, broker-validated code candidates, company profile URLs, final domain and data coverage remain implementation inputs.
All five offers remain independently testable. The supplied hypothetical prices are $3,000 per ten-SKU pilot and $750–$2,500/month per repeat lane. The pilot gate remains legal/data review, broker incorporation and importer funding; demo polish does not establish demand.
