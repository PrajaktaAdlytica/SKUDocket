SKUDocket brand kit v1.0

Start with index.html: the interactive visual catalog.
logos/: editable outlined SVG signatures and marks, SVG/ICO/PNG favicons and web manifest.
tokens/: color, spacing, type, layout, shadows and motion in CSS/JSON, plus optional Tailwind mapping.
fonts/: local desktop TTF and web WOFF2 fonts.
icons/: licensed UI SVG set/sprite and separate original social assets with source notes.
visuals/: 43 independent content figures/card diagrams, editable-text SVG masters, 3 background shapes and chart data.
illustrations/: original Harbor Atlas and Review Table PNG/WebP assets.
docs/: brand guide, 31-page visual map, original IA, component boundaries, fixture, sources and verification.
screenshots/: desktop/mobile catalog evidence after browser QA.

This kit implements the brand identity and component catalog. The planned company website remains a separate build. No real form submission, auth, filing or system write is connected.

The historical research IA in docs/information-architecture.txt is included for coverage. The selected identity and asset status in this brand kit supersede its earlier branding-phase notes.
